# 🇳🇬 NaijaLaughs

### Naija No Dull Moment!

**Nigeria, Africa, and the world — served with a twist of humour.**

NaijaLaughs is a youthful, AI-powered news and entertainment platform that brings current affairs, trending stories, business, sports, technology, and everyday Nigerian conversations to life through engaging storytelling, comedy, and cartoon-inspired visuals.

Our mission is simple: make staying informed entertaining without losing sight of accuracy, context, and responsible publishing.

---

## 🎯 What We're Building

NaijaLaughs combines the familiarity of a Nigerian news blog with the energy of internet culture, local humour, and AI-assisted content creation.

We aim to help readers stay informed, laugh a little, discover opportunities, and understand the stories shaping Nigeria, Africa, and the wider world.

## 🧠 Our AI-Powered Editorial Workflow

NaijaLaughs is designed to use AI to improve content discovery and editorial efficiency, while keeping human judgement central to publication.

1. **Discover** — Identify potentially relevant stories and trending topics.
2. **Prepare** — Generate draft descriptions, summaries, and supporting content where appropriate.
3. **Review** — Allow a human editor to assess relevance, accuracy, tone, and suitability.
4. **Approve** — Accept or reject content before publication.
5. **Publish** — Display approved content on the website.
6. **Maintain** — Preserve verified information and avoid automatically rewriting content that has already been verified.

**Our principle:** AI helps us work smarter; editorial judgement determines what gets published.

## 🚀 Getting Started

### Prerequisites

Install the following before running the application:

- Node.js and npm
- Git
- Access to the project's Supabase configuration
- Any API credentials required by the features you intend to run

### 1. Clone the repository

```bash
git clone https://github.com/Ogbaji201/Naija-Laugh
cd Naija-Laugh
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a local `.env.local` file in the project root and add the environment variables required by your application.

Typical integrations may require a Supabase project URL, a Supabase key, and an OpenAI API key. Use the exact variable names expected by the application code.

**Security:** Never commit `.env.local`, API keys, database secrets, or cron secrets to GitHub.

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

If your development server is configured to use port `3001`, open [http://localhost:3001](http://localhost:3001) instead.

### 5. Build for production

```bash
npm run build
```

Run this command to check whether the application builds successfully for production.
